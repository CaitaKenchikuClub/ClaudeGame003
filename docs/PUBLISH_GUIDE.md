# GitHub Pages で公開する手順（初めての方向け）

ゲームのファイルは、Claude が GitHub リポジトリ
**CaitaKenchikuClub/ClaudeGame003** の作業用ブランチ `claude/ecstatic-hypatia-xvwuy1` にアップロード済みです。
あなたが行う操作は、次の **2つ** だけです。

1. 作業用ブランチの内容を `main` ブランチに取り込む（マージ）
2. GitHub Pages を有効にする

> **用語メモ**
> - **リポジトリ**：プロジェクトのファイルを入れておく GitHub 上の箱
> - **ブランチ**：ファイルの「作業コピー」。`main` が正式版
> - **プルリクエスト（PR）**：「この作業コピーを正式版に取り込んでいいですか？」という確認の申請
> - **マージ**：作業コピーを正式版に取り込むこと

---

## 手順1：作業用ブランチを main に取り込む

1. パソコンかスマホのブラウザで https://github.com/CaitaKenchikuClub/ClaudeGame003 を開く（ログインしておく）
2. 画面の上に黄色い帯で **「claude/ecstatic-hypatia-xvwuy1 had recent pushes」** と表示されていたら、**「Compare & pull request」** ボタンを押す
   - 帯が表示されないとき：上のタブの **「Pull requests」** → **「New pull request」** → 「compare:」の欄で `claude/ecstatic-hypatia-xvwuy1` を選ぶ
3. 「base: **main**」←「compare: **claude/ecstatic-hypatia-xvwuy1**」になっていることを確認し、**「Create pull request」** を押す
4. 次の画面で **「Merge pull request」** → **「Confirm merge」** を押す
5. 「Merged」という紫色の表示が出れば完了です

> Claude に「プルリクエストを作って」と頼めば、手順2〜3を代わりに行います。その場合、あなたは手順4のマージだけを行えば済みます。

## 手順2：GitHub Pages を有効にする

1. リポジトリのページ上部にある **「Settings」**（歯車アイコン）を押す
   - スマホで表示されないときは、画面を横にスクロールするか、ブラウザを「PC版サイト」表示に切り替えてください
2. 左のメニューから **「Pages」** を押す
3. **「Build and deployment」** の欄で、次のように設定する
   - **Source**：`Deploy from a branch`
   - **Branch**：`main` を選び、その右のフォルダは `/ (root)` を選ぶ
4. **「Save」** を押す
5. 1〜3分待ってからページを再読み込みすると、上部に
   **「Your site is live at https://caitakenchikuclub.github.io/ClaudeGame003/」** と表示されます

## 手順3：公開されたゲームを確認する

1. スマホで **https://caitakenchikuclub.github.io/ClaudeGame003/** を開く
2. 次の点を確認し、問題があれば Claude に伝えてください（スクリーンショットがあると助かります）
   - [ ] タイトル画面とキャラの画像が表示される
   - [ ] 「はじめる」でゲームが始まり、指でドラッグして動かせる
   - [ ] 音が鳴る（マナーモードは解除しておく）。右上のボタンで消音できる
   - [ ] ゲームオーバー後に「もう一回」で再スタートできる
   - [ ] ページを開き直してもベストスコアが残っている
   - [ ] 画面の上下（ノッチやホームバー付近）で表示が欠けていない

> **ホーム画面に追加**：iPhone なら Safari の共有ボタン →「ホーム画面に追加」、Android なら Chrome のメニュー →「ホーム画面に追加」で、アプリのように起動できます。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 404 エラーが出る | 公開の準備に数分かかります。5分ほど待ってから再読み込みしてください。それでも出る場合は、手順2の Branch が `main` と `/ (root)` になっているか確認してください |
| 古い内容が表示される | ブラウザのキャッシュが残っています。再読み込みするか、少し時間をおいてから開いてください |
| Settings に Pages がない | リポジトリが「Private（非公開）」の場合、無料プランでは Pages を使えません（このリポジトリは現在 Public なので問題ありません） |

## 今後 Claude Code で開発を続けるには

### 依頼のしかた
1. https://claude.ai/code を開き、リポジトリ **CaitaKenchikuClub/ClaudeGame003** を選んで新しいセッションを始める
2. やりたいことを日本語で伝える。例：
   - 「GAME_SPEC.md の既知の不具合 #1 を直して」
   - 「スマホのホーム画面用のアイコンを追加して」
   - 「一時停止ボタンを追加して。見た目は今のボタンに合わせて」
3. Claude は `CLAUDE.md` を読んでから作業するので、毎回方針を説明し直す必要はありません
4. Claude が作業用ブランチにアップロードしたら、「プルリクエストを作って」と頼む → 内容を確認して **Merge** → 1〜2分で公開中のゲームに反映されます

### 上手に頼むコツ
- **1回の依頼で1つの変更**にする（問題が起きたときに戻しやすくするため）
- 見た目を変えたくない部分は「〜は変えないで」とはっきり伝える
- 実機で気づいたことは、端末名（例：iPhone 15、Pixel 8）とスクリーンショットを添えて伝える
- 変更を取り消したいときは「さっきの変更を元に戻して」と頼めば、Git の履歴から戻せます
