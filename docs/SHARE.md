# 結果共有（シェア）の仕組みと設定

最終更新：2026-10-16（Web 版まで実装・確認。Android アプリ版は共有プラグインの組み込み・実機確認が未実施）

## 1. 何ができるか
結果画面（ごちそうさま!）の「もう一回」の下にある **［結果をシェア］** を押すと、共有用の画像をその場で作り、プレビュー画面を開く。

| ボタン | Android アプリ版（Capacitor） | Web 版（スマホ） | Web 版（パソコンなど） |
|---|---|---|---|
| 画像付きでシェア | 画像を一時保存し、共有シートに画像とテキストを渡す | ブラウザの共有機能（Web Share）で画像とテキストを渡す | 共有機能がなければボタンを出さない |
| テキストだけシェア | 共有シート | ブラウザの共有機能 | X の投稿画面を開く |
| 画像を保存 | 出さない（共有シートの「保存」などを使う） | PNG をダウンロード | PNG をダウンロード |
| とじる | — | — | — |

- 共有をキャンセルしてもエラーにはしない。プレビュー画面を開いている間はバナー広告を隠す。
- `share.js` が読み込めないときは［結果をシェア］を出さない（ゲームはそのまま動く）。

## 2. 共有画像（1080×1080 PNG）
- **スクリーンショットではなく**、Canvas に一から描く。端末の画面サイズや解像度に関係なく、同じスコアなら**毎回まったく同じ画像**になる（自動テストで確認済み）。
- 乱数を使わない。同梱フォント（Dela Gothic One、M PLUS Rounded 1c）とキャラ画像の読み込みを待ってから描く。AI 画像生成サービスは使わない。
- 内容：タイトル「ブロッ校長！」／スコアのカード（SCORE と数字。桁が多いと文字を自動で小さくする）／キャラ「校長」（いつもの表情。`assets/img/chara.webp`）とカゴのブロッコリー／ゲームと同じ描き方のブロッコリー（金も含む）・空・雲・草地／下に「#ブロッ校長」と「by けんちくぶ！」。
- X などでテキストが消えても、画像だけでゲーム名・スコア・ハッシュタグが分かるようにしている。
- ファイル名：`burokocho-{スコア}.png`。大きさは約 0.6MB。

## 3. 共有テキスト
```
『ブロッ校長！』で遊んだよ！
SCORE: {スコア}
#ブロッ校長 byけんちくぶ！
```
- スコアは数字だけ（「点」などは付けない）。URL は入れない。（2026-10-16 変更）

## 4. 設定の変え方（`share-config.js`）
- `textTemplate`：共有テキスト（`{score}` がスコアに置き換わる）
- `title` / `hashtag` / `byline`：画像の中の文字
- `character`：画像に描くキャラの画像ファイル
- `fileName`：保存・共有するファイル名
- 画像のレイアウト（位置・大きさ）は `share.js` の `renderResultImage` にある。

## 5. Android アプリ化（Capacitor 導入時）にやること
1. `npm i @capacitor/share@8 @capacitor/filesystem@8` → `npx cap sync`（2026-10-16 時点で share 8.0.3、filesystem 8.1.5）
2. `share.js` はこの2つのプラグインがあれば自動で使う：画像を `CACHE`（アプリのキャッシュ）の `share/` に書き出し、`Share.share({ text, files: [uri] })` で共有シートを開く。
3. 実機で確認する（**まだ確認していない**）：
   - 共有シートが開き、X・LINE・Instagram などに画像が渡るか。テキストも一緒に渡るか（アプリによっては画像だけになる）
   - 「ファイルに保存」「フォトに保存」などで画像を保存できるか
   - 共有をキャンセルしたとき、ゲームに戻れるか
4. 共有に使う一時ファイルは、アプリのキャッシュにあるので、端末が自動で整理する。

## 6. 確認方法
- `node tests/share-test.mjs`：ボタンの表示条件、画像の大きさ・形式・同じ見た目、保存、テキスト、Web Share（画像・テキスト）、未対応ブラウザ、キャンセル、Esc キー、アプリ版の流れ（プラグインは模擬）、share.js が無いとき。
- テストを実行すると、画像の見本が `tests/share-sample.png` にできる（git の管理対象外）。
